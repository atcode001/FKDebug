# FKDebug 使用文档

## 界面概览

FKDebug 是一款 Android 调试辅助工具，主界面分为以下几个区域：

- **标题栏**：窗口控制按钮（最小化、最大化、关闭）
- **日志标签区**：local / frida / dmesg / logcat 四个内置日志标签页，以及文件管理器、工具窗口等动态标签页
- **日志列表面板**（左侧）：显示各来源的日志信息
- **详情面板**（日志与设备面板之间）：查看日志详情、编辑内容
- **设备进程面板**（右侧）：设备管理、进程控制、脚本管理、FKLoader 配置、KPM 模块、小工具
- **状态栏**：MCP 服务状态、主题切换、字体大小

---

## 1. 标题栏

标题栏位于窗口顶部，显示软件名称和当前设备 ID，右侧提供三个窗口操作按钮：

| 按钮 | 功能 |
|------|------|
| **—** | 最小化窗口 |
| **□** | 最大化/还原窗口 |
| **✕** | 关闭窗口 |

- 双击标题栏空白区域可切换最大化/还原。
- 拖拽标题栏可移动窗口。

---

## 2. 日志标签页

主界面左侧上方为 AvalonDock 标签容器，包含四个内置日志标签和动态打开的标签：

| 标签 | 说明 |
|------|------|
| **local** | 本地脚本日志输出 |
| **frida** | Frida 脚本日志输出 |
| **dmesg** | 内核日志（dmesg） |
| **logcat** | Android logcat 日志 |

- 标签支持拖拽分离为独立窗口
- 未激活标签有新消息时显示角标
- 右键可关闭动态标签（文件管理器、工具窗口等）

---

## 3. 日志列表

每个日志标签页包含一个日志列表和一个底部过滤栏。

### 3.1 列表列说明

#### local / frida / dmesg 日志列

| 列 | 说明 |
|------|------|
| **#** | 日志序号 |
| **时间** | 日志时间 |
| **脚本类型** | 脚本类型（表头下拉可过滤） |
| **消息** | 日志内容（表头含搜索框） |
| **LV** | 日志级别（表头下拉可过滤） |

#### logcat 日志列

| 列 | 说明 |
|------|------|
| **#** | 日志序号 |
| **时间** | 日志时间 |
| **PID-TID** | 进程/线程 ID（表头输入框可过滤） |
| **TAG/包名/消息** | 复合列：TAG \| 包名 \| 消息内容（表头含搜索框） |
| **LV** | 日志级别（表头下拉可过滤） |

### 3.2 快捷搜索

- 在日志列表表头搜索框中输入关键词，可实时过滤日志内容
- 快捷过滤支持同时搜索级别、PID、TID、TAG、包名、消息

### 3.3 右键菜单

#### local / frida / dmesg 日志右键菜单

| 菜单项 | 功能 |
|--------|------|
| **清空日志** | 清空当前列表所有日志 |
| **重新加载** | 重新加载日志 |
| **停止采集** | 停止日志采集（dmesg/logcat 子类有效） |
| **开始采集** | 开始日志采集（dmesg/logcat 子类有效） |
| **添加过滤** | 新增过滤条件 |
| **复制 → 全部复制** | 复制选中日志行 |
| **复制 → 解析Json复制...** | 解析日志中的 JSON 并复制 |
| **保存 → 仅数据** | 保存日志数据（JSON） |
| **保存 → 完整日志** | 保存完整日志（逐行 JSON） |
| **整理 → 还原** | 还原去重前的日志排列 |
| **整理 → 去重** | 去除重复日志（排除指定 JSON 字段） |
| **整理 → 排序 → 按日志排序** | 按日志内容排序 |
| **整理 → 排序 → 按Json key排序...** | 按 JSON key 排序 |
| **打开日志文件** | 打开已保存的日志文件（.log/.json） |

#### logcat 日志右键菜单

| 菜单项 | 功能 |
|--------|------|
| **清空日志** | 清空当前列表所有日志 |
| **重新加载** | 重新加载日志 |
| **停止采集** | 停止 logcat 采集 |
| **开始采集** | 开始 logcat 采集 |
| **打开日志文件** | 打开已保存的日志文件 |

### 3.4 底部过滤栏

日志列表底部显示当前已启用的过滤器按钮：

- 点击过滤按钮可启用/切换过滤
- **右键点击过滤按钮**：
  - **编辑过滤器**：修改过滤器条件
  - **删除过滤器**：移除该过滤器

## 5. 设备进程面板（右侧）

右侧面板是 FKDebug 的核心功能区，以垂直排列的区域（非标签页）组织，通过折叠按钮展开/收起各区域。

### 5.1 通用操作

- **折叠按钮 ▶/◀**：点击可折叠/展开右侧面板
- 面板折叠后，仅显示精简的启动/重启/附加/剥离/加载/卸载/重载按钮

### 5.2 设备选择区

- **设备下拉框**：选择连接的 Android 设备
- **刷新按钮 ⟳**：刷新设备列表和进程列表
- **root 输入框**：配置 su 命令名称（默认 `su`）
- **adb 输入框**：配置 adb 路径

### 5.3 Gadget 工具条

显示 Frida gadget 相关操作按钮：

| 按钮 | 功能 |
|------|------|
| **安装** | 安装应用 |
| **脚本模式** | 切换为 Spawn 启动模式 |
| **监听模式** | 切换为监听（Attach）模式 |
| **启动** | Spawn 启动进程 |
| **重启** | 重启任务 |
| **附加** | Attach 到进程 |
| **剥离** | 剥离脚本会话 |

### 5.4 进程列表

- 显示设备上的进程列表，含包名和 PID
- **搜索框**：输入关键词过滤进程
- **调试进程**：显示当前设置的调试进程名
- **展开/收起按钮 ▲/▼**：切换进程列表显示/隐藏

**进程右键菜单**：

| 菜单项 | 功能 |
|--------|------|
| **设置为调试进程** | 将选中进程设为调试目标 |
| **设置为调试包名** | 将选中进程的包名设为调试包名 |
| **结束进程** | 强制结束选中进程 |
| **清理数据** | 清理应用数据 |
| **启用FKLoader** | 启用 FKLoader |
| **禁用FKLoader** | 禁用 FKLoader |
| **刷新进程** | 刷新进程列表 |

**Gadget 弹出列表右键菜单**：

| 菜单项 | 功能 |
|--------|------|
| **启动进程** | 启动 gadget 进程 |
| **杀死进程** | 终止 gadget 进程 |
| **清理数据** | 清理应用数据 |

### 5.5 脚本区

- **展开/收起按钮 ▲/▼**：切换常用脚本列表显示/隐藏

**简单脚本**：以 CheckBox 形式显示，勾选即启用
**复杂脚本**：每个独立一行，包含主 CheckBox 和参数控件
**自定义脚本**：勾选启用，从下拉框选择自定义脚本文件

### 5.6 FKLoader 配置

FKLoader 是内置的注入框架配置管理。

**未安装状态**：显示提示信息和 **安装FKLoader** 按钮。

**已安装状态**：

- **左侧**：已配置的目标应用列表

| 列 | 说明 |
|------|------|
| **启用** | 勾选启用该目标 |
| **包名** | 应用包名 |

**左侧右键菜单**：

| 菜单项 | 功能 |
|--------|------|
| **刷新** | 刷新配置 |
| **删除目标** | 删除选中目标 |
| **同步到手机** | 同步配置到手机 |

- **右侧**：选中目标的注入库管理
  - 库路径输入框 + 添加按钮
  - 库列表右键菜单含 **删除库**

### 5.7 KPM 模块

KPM（Kernel Patch Module）内核补丁模块管理区域。

| 列 | 说明 |
|------|------|
| **模块** | 模块名称 |
| **状态** | 模块加载状态 |
| **操作** | 加载/卸载按钮 |

**右键菜单**：

| 菜单项 | 功能 |
|--------|------|
| **加载模块** | 加载选中模块 |
| **卸载模块** | 卸载选中模块 |

### 5.8 小工具

在设备面板底部，提供四个便捷工具按钮，点击后以新标签页打开：

| 按钮 | 功能 |
|------|------|
| **编码** | 编码转换工具（Base64/Hex/Unicode 等互转） |
| **时间戳** | 时间戳转换工具 |
| **Hash** | Hash 计算工具（MD5/SHA1/SHA256 等数十种算法） |
| **JSON对比** | JSON 差异对比工具 |

## 6. 文件管理器

点击主窗口左下角 **文件管理** 按钮或通过 MCP 调用，以新标签页形式打开文件管理器。支持电脑与手机之间的文件推送和拉取，以及文件浏览。

- **推送按钮**：执行推送操作
- **手机路径**：目标手机文件路径
- **推送列表**：显示推送记录（含自动推送勾选项）

### 6.2 拉取列表

- **拉取列表**：显示拉取记录

## 注意事项

1. 首次启动时需选择工作文件夹，用于保存脚本、日志、配置文件等数据。
2. 启动时自动检测工作目录下的 `fridaJs` 脚本目录，如果不存在则弹窗询问是否从 `https://github.com/atcode001/FKDebugJS.git` 克隆。
3. 使用 ADB 功能前请确保 Android 设备已通过 USB 连接并开启调试模式。
4. FKLoader 配置修改后需点击 **同步到手机** 才能生效。
5. 日志搜索支持实时过滤，输入关键词即自动筛选。
6. MCP 服务启动时如果端口被占用，会提示错误信息而不会崩溃，可通过状态栏右键菜单更换端口。
7. 工作目录结构：
   - `fridaJs/` - Frida 脚本目录（启动时可选自动克隆）
   - `logs/` - 日志文件存储目录
   - `temp/` - 临时文件目录（启动时自动清理）
   - `crash/` - 崩溃日志目录
   - `dumpso/` - dumped SO 文件目录
   - `dump_dex/` - dumped DEX 文件目录
   - `fktrace/` - Frida trace 数据目录
   - `savefile/` - 脚本保存文件目录
   - `gadget/` - Frida gadget 二进制文件目录
